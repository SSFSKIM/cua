# #398 hosted measurement and qualification: the placeholder in element identity

A disposable hosted macOS kit, not product code. It measures, on GitHub-hosted macOS, (1) how often the placeholder is the only attribute that separates two text fields of one window, by the engine's own identity match, and (2) how main answers when a field's placeholder changes between the observation and the action. It then qualifies the #398 fix (the placeholder leaves `ElementIdentity`'s strict match and only breaks a tie among otherwise-matching candidates) against main. Built from `probe/361-qual`'s lanes (exact-SHA stock builds, the owned cover and activation witness, the long-poll fixture server, one engine connection per trial) and `probe/414-qual`'s AppKit fixture pattern; the helpers it needs are copied here (`proc.mjs`, `wire.mjs`, `fixture-server.mjs`, `host.swift`) so the kit stands on main alone.

```sh
gh workflow run probe-398-qual.yml --ref probe/398-qual -f main="$MAIN_SHA" -f mode=measure                       # Phase 1: census and main alone
gh workflow run probe-398-qual.yml --ref probe/398-qual -f main="$MAIN_SHA" -f fix="$FIX_SHA" -f mode=qualify -f census=omit
```

## The census (`census.mjs`, `phase=census`, main only)

- **Engine.** An instrumented copy of main (`patch-census.mjs`): `ElementIdentity.matches` gains `ignoringPlaceholder` (default false, so every existing call is unchanged), and every committed observation, on `PROBE398_CENSUS=1`, reports its text fields (`AXTextField`, `AXTextArea`, `AXComboBox`, `AXSearchField`, `AXSecureTextField`) and, for each pair of them in the observed window, whether the engine's own match separates them only by the placeholder (`matches` false, `matches(ignoringPlaceholder:)` true) or not at all (`matches` true), with the value counted (an `.ifNeeded` re-read) and without it (set_value's `.ignoringValue` re-check). Each pair also records its **lineage of parents**: whether every ancestor, level by level, matches its counterpart (`ancestryAlike`), whether the two are siblings, and how far up their nearest common ancestor is. Only roles, subroles and each attribute's shape (absent, empty, set) leave the engine, never an attribute's text (`Probe398Census.swift`). The vendor runtime is never used.
- **Pages.** 45 public pages that need no login (`sites.mjs`): sign-up and account forms, checkout, address and tracking forms, search pages and search-led sites, settings-like pages; in Chrome for Testing (one tab per page through its DevTools endpoint) and Safari (`open`, closed with ⌘W). Each page is loaded for 8 s, observed, and observed again 2.5 s later (after Chromium's complete accessibility mode); the second observation is the census. A page counts as reached when one of its web areas is on the requested site (`hostMatch`); bot walls and consent pages are recorded as they are. Nothing is typed, submitted or signed in.
- **Apps.** Fifteen built-in app windows: five System Settings panes, Contacts' new card, Calendar's new event, Mail's first window, a Finder search, TextEdit's find and replace, Reminders, Notes, Keychain Access, Font Book and Maps, opened by URL or bundle with their keys posted by the census engine's own `press_key`.

## The fixture lanes (`run.mjs`, `phase=stock`)

- **Heads.** Unmodified release builds of exact SHAs (`git worktree add --detach`, clean before and after the build). The harness drives the engine's own wire: `get_app_state`, then `click` and `set_value` or `type_text` with the observation's token and lineage, one engine connection (so one fresh lineage) per trial; only the head under trial holds a connection.
- **Lanes.** Chrome for Testing, Safari, Electron (`electron/`, Electron 44.4.5) on the owned page (`page.mjs`), and an owned AppKit fixture (`fixture.swift`: `NSTextField`s and an `NSSearchField`). Each lane tries the background under the owned cover with #395's activation witness, and falls back to frontmost only when the background could not be set up before any cua call.
- **Fields.** Each placeholder-change field carries its own label (aria-label, AppKit accessibility label), so the placeholder is the only attribute that changes: `static` (never changes: the control), `focus` (cleared on focus, restored on blur: a floating label), `rotate` (rotates every 150 ms while its cell runs: "search people…", "search files…"), `input` (switches on the first input: a mode hint), `search` (an `<input type=search>` or `NSSearchField` whose hint switches on focus). The **twins** are two fields alike in everything but their placeholder (same label, type and parent), rebuilt at every prepare.
- **Units**, ten per unit per head to measure, twenty to qualify, the heads interleaved (`cells.mjs`):
  - each placeholder field × `set` (click its element, then set_value on the same element) and `type` (click it, then type_text; skipped when the click refused);
  - the stale-handle twins, `set` only: between the observation and the click the first twin is recreated alike (`twin-recreate`: the right answer is success into it), recreated with another placeholder (`twin-renamed`: success into it or a refusal; never the other twin), or removed (`twin-removed`: the right answer is a refusal).
- **Per trial**: the click's and the second action's outcomes (success or the engine's error name), the field's settled content (the fixture's own boolean, polled up to 2 s and read again 300 ms later), whether the target is still the node the observation named (`sameNode`), how often its placeholder changed after the observation (`realized`), any other field written or focused (`wrongAdoption`), what the observation showed of the placeholder, the witness, and the engine-call times.
- **Verdicts** (`check.mjs`): `success-exact`; `refused-delivered` (an error while the value went in, e.g. `valueUnconfirmed`); `refused`; `click-refused` (type unit, the click refused); `wrong-success`; `wrong-adoption`. A **placeholder-only refusal** is an identity refusal (`elementNoLongerValid`, `valueUnconfirmed`, either ambiguity) while the target is the same node, present, and its placeholder changed after the observation. A setup failure before the first action is an invalid row with its step, never a product miss.

**Gates** (`check.mjs` `gates`, qualify only): coverage (every planned row ran, and every unit of every head kept 80% of its rows valid); every valid fix row of a placeholder unit is an exact success with a successful click; no wrong adoption and no wrong success on the fix; every `twin-removed` fix row refused; every `twin-recreate` fix row an exact success; no paired row where main succeeded exactly and the fix did not.

`report.mjs <dir>` prints the tables from a downloaded run (`gh run download <id> -D <dir>`).
