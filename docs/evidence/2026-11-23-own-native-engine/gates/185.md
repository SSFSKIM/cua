## The change

Commit `762875484`: "native matrix: r k composes 가 under engaged Korean and rk under Latin; the per-context rows run,
not judged (refs #189, #185)". Changes:

- `scripts/native-matrix/unicode-plan.mjs`: `NOT_JUDGED = {perContext: <the cause>}`. The cause reads: "out of M5's
  judged matrix (ruling 1119, #185): a stored per-context preference does not show live behaviour, and establishing
  it would mean focusing each window, which non-interference forbids". The plan still holds the condition's 54 rows
  (three fields, nine strings, typeText and paste). A declaration never applies to an excluded row.
- `scripts/native-matrix/unicode-run.mjs`: `perContextRows` runs as before, with the same readings and the same
  invalid reasons. The section then marks each of its rows `excluded` with the cause, held or not, passed or failed.
- `scripts/native-matrix/cell-result.mjs`: a row's optional `excluded` cause, validated as a reason. A cell's verdict
  counts an excluded row for nothing, as it counts an invalid one. A cell holding only excluded rows is `no-verdict`,
  never a pass and never a fail.
- `scripts/native-matrix/summary.mjs`: the judge leaves the per-context rows out of the manifest, the judged Unicode
  rows, the interference count and the declarations. It does so by their condition, so rows recorded before the ruling
  (hold 3's, which carry no `excluded`) are left out too. The judgment's `notJudged` lists every per-context row of the
  plan with its condition, its cause, and each engine's ok/valid/invalid counts, even for a run that has none. The
  report adds a **Not judged** section after "Korean and Unicode", grouped by condition with the cause once. The
  three-point line says "… rows pass on cua; 54 perContext rows are not judged (below)." Nothing in the not-judged list
  reaches Blocking, Missing proof or For the owner.

### The fix wave (task review)

The review found three faults, now fixed:

- **Any row could be taken out of the verdict.** Any `excluded` string did it, a required row's included: the
  reviewer marked the Korean pressKey row failed and excluded, and the verdict was PASS. Now the rule lives in one
  module, `scripts/native-matrix/not-judged.mjs` (`NOT_JUDGED`, `exclusionOf`). It decides by section and condition
  alone, and the cell verdict, the reader and the judge all read it. A row's mark is only the run's record:
  - an `excluded` mark on any other row makes its result non-conforming, so `readResults` names it as missing proof;
  - such a row is still judged as it read;
  - the judge also names the mark when a result reaches it without the reader's check.
- **The exclusion marks were lost if the section threw.** `unicode-run.mjs` marked rows only after the section
  returned, so a throw in the per-context setup left an incomplete run with no excluded rows. Two changes:
  - the marks are now applied in a `finally`;
  - a per-context setup step that throws, such as the preference's write, now fails that condition alone. Its rows are
    invalid with "the per-context setup failed: <error>", they carry the cause, the error is kept in
    `meta.unicode.readings`, and the run goes on.

  A `Stop` (an interrupt, the owner at the Mac) is never caught. The input sections' restore still verifies the
  preference, and an unconfirmed restore still leaves the run incomplete.
- **Unrecorded rows looked like rows that ran.** A not-judged row of the plan that no lane recorded now reads "not
  recorded" in the report (`recorded: false` in `notJudged`), which is distinct from an invalid sample.

## Runner witness (prepared, not run)

The 54 per-context rows (`<field>/perContext@<user>/<typeText|paste>.<string>`, fields textedit, chrome and electron)
on a GitHub-hosted macOS runner, both engines. They are part of sitting C, which runs the full plan. The witness is

  --host <vendor|cua> --engine <vendor|cua> --approved-runtime <the run's CUA_HOME> \
  --approved-engine <the run's cua Engine.app> --sitting <id> --out <dir>

Then run `node scripts/native-matrix.mjs summary <dir>` on sitting C's full runs.
